# Mockup — Radar Financeiro

Referência visual da V2 (somente leitura). Valores numéricos são placeholders.

- `preview/*.html`: versões autônomas, abrem direto no navegador ou no Playwright (viewport mobile 390×844; web 1440×900). Use para comparar screenshots.
- `source/*.dc.html`: arquivos originais do editor de design (HTML/CSS inline = fonte da verdade de cores, fontes, raios e espaçamentos).
- `source/canvas.json`: posição e tamanho de cada artboard.

Artboards: Painel, Ativo (Brasil/Mundo), Cripto, Entenda (mobile, claro e escuro) e Web-Painel (claro e escuro).
